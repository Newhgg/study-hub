## 如何更新

### 更新政策库
1. 修改 `政策库/index.html` 或 `政策库/auto-policies.js`
2. 重新部署：`tcb hosting:deploy ./ -e 环境ID`

### 更新影音库
1. 修改 `影音库/index.html`
2. 重新部署

### 更新二维码
1. 编辑 `部署/gen_qrcode.py`，替换 `BASE_URL`
2. 运行：`python 部署/gen_qrcode.py`

## 技术说明

- 纯静态 HTML/CSS/JS，无后端依赖，加载快
- 部署在腾讯云 CloudBase（国内访问快，微信兼容好）
- 响应式设计，手机/电脑均可正常使用
- 政策数据来自官方渠道，可放心查阅
- 手动添加的政策存储在浏览器 localStorage，支持导出 JSON 备份
